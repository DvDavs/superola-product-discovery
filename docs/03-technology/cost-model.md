# Cost Model — Framework Placeholder

> Status: INPUTS NOT VALIDATED. P00 contains no production cost estimate.

## Cost categories

- Initial development and migration effort.
- Monthly fixed platform/services cost.
- Usage-variable cost and the units that drive it.
- Developer time and operational/on-call burden.
- Security, privacy, compliance, support, and moderation burden.
- Data transfer, storage lifecycle, backup/restore, and observability.
- Vendor lock-in, contract exposure, exit, and re-platforming cost.

## Required scenario model

Later phases should model at least a minimal launch, validated near-term growth, and an explicit scale threshold. Each scenario needs volumes, unit prices with access dates, uncertainty/ranges, excluded costs, and sensitivity drivers.

## Principle

Optimize total cost of ownership and delivery risk, not only the cheapest infrastructure bill. Every recommendation needs a reconsideration trigger.
