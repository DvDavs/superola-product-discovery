# User Journeys — P01 Placeholder

> Status: NOT STARTED. The sequences below are `PROPOSED` hypotheses for validation, not requirements.

## Customer hypothesis

Define event need → discover by service/geography → filter/evaluate provider → check or request availability → start an in-platform conversation/request → receive quote → decide → potentially book/pay → receive service → review.

## Provider hypothesis

Register/claim business → establish profile and services → define geography and availability → receive qualified request → communicate/respond with quote → potentially confirm booking/payment → deliver service → build reputation → manage plan/promotion.

## Validation needed

- Entry points, actors, abandonment risks, trust signals, response-time expectations, negotiation behavior, category differences, and offline escape routes.
- Exact MVP stopping point: lead/contact, request/quote, booking, or payment.
- Empty, error, abuse, cancellation, no-response, and dispute states.
