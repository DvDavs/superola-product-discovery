# Research Work Packages

P03 and later phases use this directory for bounded, current, source-backed comparisons. P00 creates the backlog only; it performs no comprehensive technology selection.

Every completed research note must include:

- decision problem and validated requirements;
- candidate A/B/C where appropriate;
- capabilities and limitations;
- current pricing with currency, units, region, access date, and official source;
- development and operational effort;
- scaling and failure characteristics;
- security, privacy, compliance, terms, and data implications;
- lock-in and exit path;
- recommendation status (`PROPOSED` until approved);
- measurable reconsideration trigger;
- authoritative sources and unresolved questions.
