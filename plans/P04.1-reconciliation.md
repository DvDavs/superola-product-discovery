### 2. `RequestDraft` local-draft privacy boundary (`R-050`)

Added `docs/04-ux/request-intake.md` §4.6, five new rules (`RD-17`–`RD-21`):

- **Structured answers only**: the anonymous local draft never writes `GC-12`'s free-text notes field to browser storage; it is held in page memory for that session only until an `Account` exists.
- **Visible discard**: an explicit "discard this draft" action, distinct from navigating away.
- **Clear-on-promotion**: the local copy is deleted the moment it promotes to a server `RequestDraft`.
- **Local expiry**: the mechanism is required to exist; its window is `POLICY PENDING`, consistent with how `NoResponse` and the `RequestIntake` decay window are already handled.
- **`RD-21`**: whether this contract requires disclosure, and whether anonymous local storage is acceptable at all, is left `OPEN` at `Q-038` — David + counsel. **Not answered by this phase.**

### 3. Date / lead-time / `flexible` / `LocationEligibility` / `G-06`

Added one explicit reconciling paragraph to `docs/04-ux/request-intake.md` §7.3 (Delivery and food) explaining why the archetype's lead-time `LocationEligibility` predicate does not reopen `G-06`: it is a deterministic logistics-feasibility test over the provider's own declared production constraint, not a claim that the provider is free — actual feasibility is still resolved only inside the request exchange, exactly as `IQ-04` already requires for every other archetype. `flexible` producing `undetermined` (rather than being skipped or defaulted to `eligible`) is named as the mechanism that keeps this a logistics filter rather than an availability claim.

### 5. Mobile-performer map link-out (`PP-63`)

Removed the control from both artifacts and replaced it with an explanatory note; tightened the general constraint `WF-C-01` in `wireframes.md` §12, which previously read as if every surface got a map link-out, to name the fixed-venue-address condition explicitly.

Files: `docs/04-ux/wireframes.md` (desktop annotation, phone layout, annotation 6, `WF-C-01`), `presentation/superola-ux-walkthrough-v0.1.html`.
